считались токи и инъекции `branch_calc`.

Невязка P/Q на PQ-узлах при НОМИНАЛЬНЫХ нагрузках:
RMS P = 14.68 МВт, RMS Q = 16.83 МВар (ожидаемо велико из-за СХН/шунтов;
топ-10 узлов по невязке: 27, 26, 25, 22, 17, 24, 20, 23, 16, 14).

Осталось гипотезой: большая невязка на отдельных PQ-узлах объясняется СХН и
неучтёнными шунтами (проверяется на этапе B). Результат: `reports/phys_a.json`.

## Этап B — идентификация параметров

Выборка: 2000 валидных опытов с узлом 999 (seed=42). `scripts/phys_b_check.py`,
`scripts/phys_b4_probe.py`, `scripts/phys_shunts.py`. Результаты: `reports/phys_b.json`.

### B1. СХН по активной мощности (17 нагрузочных узлов)
- Пул: `r = P_факт/P_н = V_pu^k`, k = **0.5037**, остаток RMS P = 1.600 МВт.
- Квадратичная: `r = 0.82348 − 0.28546·V + 0.46204·V²`, остаток RMS P = **0.117 МВт**
  (на узле максимум 0.234 МВт).
- По классам: 110 кВ — k=0.5034, RMS 1.635 МВт; 220 кВ — k=0.5050, RMS 1.461 МВт.
  Нагрузочных узлов 500 кВ нет.
- Разброс k по узлам: std=0.047, min=0.472, max=0.672.

### B2. СХН по Q и шунты (17 узлов)
Модель `Q_calc ≈ −Q_н·(d0+d1·V+d2·V²) + q_sh·V²`, МНК по узлу.
- RMS Q: медиана **0.092 МВар**, максимум 0.551 МВар (узел 25).
- Топ по остатку: 25 (0.55), 22 (0.44), 27 (0.43), 20 (0.40), 24 (0.37) МВар.

### B3. Регулируемые узлы

|---|---|---|---|

Узел 3 почти всегда за пределом Q≈500 → подтверждает гипотезу Qmax≈500 и переход
PV→PQ. Узел 1 лимит 500 срабатывает редко (0.3% опытов).

### B4. Узлы 13, 29, 33 (проверено числом)
- **13**: V строго 230 кВ; `P_calc + P_н·f(V)` = **600.00 МВт**, std **0.042 МВт**.
  => PV-узел с постоянной активной генерацией ≈600 МВт и V=230; Q свободен.
  Подтверждено (std << 1 МВт).
- **29**: `P_calc + P_н·f(V)` = **300.00 МВт**, std **0.080 МВт**;
  corr(P_calc, P_г) ≈ −0.03.
- **33**: = **299.94 МВт**, std **0.185 МВт**; corr(P_calc, P_г) ≈ +0.01.
  => 29/33 — PQ-узлы с постоянной генерацией ≈300 МВт; **входной P_г на физику
  не влияет** (корреляция ~0). Это подтверждено на 2000/800 опытах.
- Транзитные шунты (5,6,9–12,15,18,19): |Q_calc| < 0.6 МВар, RMS 0.03–0.08 — малы.

Критерий B: невязка P на PQ-узлах после СХН/шунтов < 2 МВт — **ПРОЙДЕНО**
(0.117 МВт пул, max по узлу 0.234 МВт). B1 завершён.

## Этап C — решатель режима (NR)

`src/nr_solver.py` (scipy `root`, method="hybr"), `scripts/phys_c_check.py`.
Модель: слэк 999 (V=510, δ=0); PV 1,2,3,4,7 (V=510), 13 (V=230, P_gen=600);
PQ 29/33 (P_gen=300); нагрузки по СХН B1 и Q-модели B2; Q-лимиты 1 и 3 = 500 МВар
с переходом PV→PQ; до 3 стартов (1.0, 0.9, 1.05) при неудаче.

Выборка: 300 валидных + 300 невалидных (seed=7), опыты с узлом 999.

| Результат | Значение |
|---|---|
| валидные: сошлось | 290/300 = **96.7%** |
| невалидные: сошлось | 2/300 = 0.7% |
| MAE V (сошедшиеся) | **0.1112 кВ** |
| MAE Delta | **0.0269°** |
| MAE I_max | 0.811 A |
| F1-macro (сходимость vs regime_valid) | **0.9800** |
| confusion (true0/1 × pred0/1) | [[298, 2], [10, 290]] |
| время / 100 опытов | 218 c |

Критерии этапа C:
- MAE V < 0.1 кВ — **НЕ ПРОЙДЕНО** (0.1112; близко). Основной вклад — транзитные
  узлы 6,5,19,18,16,15 (0.19–0.27 кВ, это ~0.05% от 500/220 кВ).
- MAE Delta < 0.05° — **ПРОЙДЕНО** (0.0269).
- F1-macro > 0.99 — **НЕ ПРОЙДЕНО** (0.98): 10 валидных опытов не сошлись
  (примеры ID: 27941, 28620, 46023, 53543, 55224, 60687, 66040, 78727, 125257, 130222),
  2 невалидных ложно сошлись.
- Решатель в сабмит не подключался. Допустимость solver по правилам — неизвестна.

Этапы, зависящие от полного прохождения C, помечены: физическое приближение для
гибрида берём как «частично пригодное» (C не пройден по V/F1).

## Этап D2 — GNN

**НЕ ВЫПОЛНЕНО.** Причина: обучение ≥300 эпох на CPU при измеренной ранее скорости
~20–25 с/эпоха (прошлый GNN-прогон) требует >100 минут; в рамках сессии не
укладывается. Ранее измеренный GNN (v2, близкая архитектура) был существенно хуже
MLP: V MAE 3.63 кВ, V R² 0.38, Delta MAE 1.14°, I_zarg MAE 3.18% — в сабмит не шёл.
Полноценная v3-архитектура (embedding узла, ≥6 слоёв, головы на рёбрах) не обучена.

## Ограничения
- Сдвиг по ID (данные упорядочены по тяжести): случайный сплит оптимистичен,
  блочный F1≈0.87. Не устранён.
- Решатель C не прошёл по V MAE (0.111>0.1) и F1 (0.98<0.99); 10/300 валидных
  near-boundary не сошлись. Остальные этапы с этим учтены.
- B3/B4 — часть выводов на ограниченных выборках: Qmax≈500 у узлов 1 и 3 (B3,
  2000 опытов) подтверждён распределением; «13 = генерация 600, V=230» и
  «29/33 = генерация 300» подтверждены с std <0.2 МВт (B4, 2000/800 опытов),
  но не проверено на всём массиве.
- Входной P_г узлов 29/33 по физике не влияет (corr≈0). Это факт данных, но
  противоречит описанию задачи — вынесено в вопросы.
- Физический solver в сабмит не подключён (правила неизвестны).
- GNN не обучена (D2 не выполнено).
